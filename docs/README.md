# Screenshot Instructions

To add a preview screenshot to the README:

1. Open https://json-formatter-validator-196.netlify.app in your browser
2. Connect the Browser MCP extension
3. Take a screenshot using the Browser MCP
4. Save it as `docs/preview.png`

Or manually:
1. Open the site
2. Use your OS screenshot tool (Cmd+Shift+4 on Mac)
3. Crop to the tool area
4. Save as `docs/preview.png`
5. Commit and push: `git add docs/preview.png && git commit -m "docs: add preview screenshot" && git push`
