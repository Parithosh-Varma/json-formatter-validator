## Core Features

- **Format** — Pretty-print JSON with proper indentation (2-space)
- **Minify** — Compress JSON to a single line
- **Validate** — Instantly check if your JSON is valid with error messages
- **Copy to Clipboard** — One-click copy of formatted output
- **Dark Mode** — Toggle between light and dark themes
- **Responsive** — Works seamlessly on desktop and mobile

## Quickstart

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools or dependencies required

### Clone & Run

```bash
# Clone the repository
git clone https://github.com/parithosh-varma/json-formatter-validator.git

# Navigate to the project
cd json-formatter-validator

# Open in browser
open index.html
```

That's it. No install step needed — it's a single HTML file.

## Design System

This tool follows the **Modern Minimal** design system:

- **Primary:** Indigo 500 (`#6366f1`)
- **Background:** Pure White / Zinc 950 (dark mode)
- **Typography:** Inter with tight tracking on headings
- **Components:** Flat buttons, clean borders, subtle shadows
- **Focus States:** Visible ring contrast for accessibility
